# Security policy

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting on this
repository (Security tab, "Report a vulnerability"), or email contact@niltv.com
with "security" in the subject. Include the repository, the affected file or
endpoint, and steps to reproduce.

We acknowledge reports within five business days. Fixes ship through the normal
pull-request flow; credit is given in the release notes if you want it.

The production systems behind these repositories (AWS, the dashboard host, the
mobile app backend) are out of scope for testing. Do not run scanners or load
tests against them; report what you find in the code instead.
